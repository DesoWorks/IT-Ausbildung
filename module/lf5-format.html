Was du lernst

  • Einen Text und eine ganze Zahl unterscheiden.
  • Eine kleine Tabelle mit benannten Feldern wählen.
  • Erkennen, warum ein Fließtext die Werte vermischt.
  • Eine Datenbank nicht wählen, wenn sie für die Karte nicht nötig ist.
Fiktiver Hinweis: Nordlicht IT-Service und Samira sind erfunden. Es gibt keine echte Datenbank und keinen ausführbaren Code.

Die Übungskarte

Samira macht ihre Ausbildung bei Nordlicht IT-Service. Sie soll auf einer Übungskarte den Gerätenamen Mira-01 und die Raumnummer 12 festhalten.

Name

Mira-01, ein Text.

Raum

12, eine ganze Zahl.

Passende Form

Eine kleine Tabelle mit zwei benannten Feldern.

Nicht nötig

Eine Datenbank für diese eine Karte.

Der Name und die Zahl bleiben getrennt, wenn jedes Feld einen eigenen Namen hat. In einem langen Satz lassen sie sich nicht sicher auseinanderhalten.

Übung: Das Format wählen

Wähle pro Aufgabe eine Antwort. Alle Fragen beziehen sich nur auf die fiktive Übungskarte.

Das nimmst du mit

  • Ein Name ist ein Text, eine Raumnummer kann eine ganze Zahl sein.
  • Benannte Felder halten die Werte getrennt.
  • Ein Fließtext vermischt, was später einzeln gebraucht wird.
  • Eine Datenbank ist nicht nötig, wenn eine kleine Tabelle reicht.

Passende Lektionen:

  • Eine kurze Dokumentation lesen
  • Daten vor dem Speichern einordnen
